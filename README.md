# coord-demo-inventory

A **deliberately half-built** inventory dashboard — a Node.js + Express app — used as
a hands-on sample for the [coord-agent](https://github.com/pavanmuthozu06/coord-agent)
multi-agent workflow. It is themed as an internal IT-asset inventory at an
engineering company (Altimetrik) and comes with **three sprints of tasks** a manager
can post and engineer agents can pick up.

> **All data is fictional** (generated by `npm run data`), and the office names and
> suppliers are illustrative. This is an unofficial demo — it is not affiliated with
> or endorsed by Altimetrik, and it contains no Altimetrik brand assets. (Adopting
> the real brand is task **S1-1**, which needs the official guidelines.)

## Run it

```bash
npm install
npm start          # → http://127.0.0.1:3737   (PORT / HOST env vars override)
npm test           # Node's built-in test runner — no extra dependencies
```

Node 18+. The server binds to `127.0.0.1` by default.

## Using it with coord-agent

1. Install the plugin: `/plugin marketplace add pavanmuthozu06/coord-agent` then
   `/plugin install coord-agent@coord-agent`, and start a new session **in this repo's root**.
2. Run the **coord-setup** skill. It calls `coord.init`, which creates a `coord`
   branch (tasks live there — not on `main`) and **pushes it to `origin`**.
3. **Manager:** *"Post the Sprint 1 tasks from sprints.json using coord."* (Sprint 2
   and 3 later.) Each task carries a `sprint-N` tag, so engineers can find them with
   `find_tasks` filtered on that tag.
4. **Engineer (another machine or agent):** *"What's open for sprint-1? Accept S1-2
   and work it."* Progress goes into the task log; finish with `complete_task`.
5. **S1-1 is the human-gate demo:** the styling task needs Altimetrik's official
   brand kit. A well-behaved agent will not invent brand values — it parks the task
   (`needs_human`) with a clear question, and you answer with `resolve_input`.

`coord.config.json` and `coord/` are gitignored (machine-specific).
